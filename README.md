# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，加权分达到该批次**声明季节对应的放行线**即通过。四季各存一条放行线（默认均为 7），可在「季节档」专页按季调整。交评必须声明季节，缺声明直接拒交。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 季节放行线

- 春、夏、秋、冬各一条放行线，存于 `season_lines`，服务端按交评声明的季节取线判定。
- 交评表单必选季节；不带季节或季节非法，服务端返回 400 拒交。
- 审评员在顶栏「季节档」专页调整某一季的线，立刻影响该季新交评。
- 每次改线在 `season_line_history` 追加一行（季节、旧线、新线、改线人、时刻），履历只追加、旧行不被覆盖。
- 改线不回填、不改写其它季节及历史已落库结论（结论随提交当时的线固化在 cuppings 行）。
- 观察员只读四季线表与改线履历，页面无改线表单，接口对非审评员返回 403。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 顶栏进「季节档」，把夏档放行线由 7 改成 8.5；履历出现「夏 旧线7 新线8.5」一行。
5. 声明夏季、提交香气 9 / 滋味 8 / 汤色 6（加权 7.9）→ 不通过。
6. 声明春季（春档仍为 7）提交同样 9 / 8 / 6 → 通过。
7. 不声明季节直接交评 → 服务端 400 拒交。
8. observer 进季节档只能看线表与履历，无改线入口。
